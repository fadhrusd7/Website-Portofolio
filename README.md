# Fadhil Rusadi - Personal Portfolio

Welcome to the repository for my personal portfolio website! This website is designed to showcase my skills, projects, and contact information in a clean, modern, and interactive interface.

## Features

- **Sleek & Modern UI:** Features an aesthetic dark mode by default with customizable elements using vanilla CSS.
- **Dark/Light Mode Toggle:** Allows users to easily switch between a light and dark theme.
- **Smooth Scrolling & Animations:** Provides a seamless user experience using CSS transitions and JavaScript.
- **Responsive Design:** Optimized for various device sizes to ensure the content looks great anywhere.
- **Typing Animation:** Engaging introductory text animation on the home section.

## Built With

- **HTML5:** Semantic HTML structure.
- **CSS3:** Custom styles, Flexbox, transitions, and imported Google Fonts (Poppins, Space Mono).
- **JavaScript:** Used alongside jQuery for DOM manipulations, UI toggles, and scroll interactions.

## Getting Started

To view this project locally, simply follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/fadhrusd7/Website-Portofolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Website-Portofolio
   ```
3. Open `index.html` in your favorite web browser.
   _(No package manager or build tools are required since it uses vanilla web technologies)_
